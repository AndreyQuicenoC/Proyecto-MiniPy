# 🌟 **MiniPy**: Un Lenguaje de Programación Moderno y Extensible 🌟

**MiniPy** es un lenguaje de programación en etapa inicial inspirado en los principios de **EOPL (Essentials of Programming Languages)**, diseñado para ser **simple, flexible y poderoso**. A través de su sintaxis concisa y su capacidad de extensión, **MiniPy** permite explorar y experimentar con conceptos fundamentales como:

- **Programación funcional**
- **Estructuras de control**
- **Programación orientada a objetos (OOP)**
- **Circuitos lógicos**

### 🚀 Características clave:

- Primitivas para operaciones aritméticas, lógicas y de manipulación de estructuras de datos.
- **Listas, tuplas y registros** como tipos de datos fundamentales.
- Soporte para **circuitos lógicos** y evaluación de expresiones booleanas.
- Sintaxis clara y fácil de usar, ideal para estudiantes y desarrolladores.

MiniPy está pensado para **proyectos educativos** y de **familiarización con la programación**, y es una excelente opción para aprender y aplicar conceptos de programación fundamental en un entorno accesible.
